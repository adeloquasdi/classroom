# Classroom Hub

This is a self-service repository for accessing your coding assignments through GitHub.

You should almost always use a link provided for you to access the forms here, but if you need to manually submit a form for whatever reason:

```
  [ <> Code ]  [ ⊙ Issues ]  [ ⇄ Pull requests ]  ...      1. click the  "Issues"  tab  ↑
                                                            2. click the green  [ New issue ]  button (top-right)
                                                            3. pick a form (below)
```


# Available Forms

## 1. Register
Fill in **Name**, **Email**, and **Join Code**. This connects your GitHub account to the class roster. If you make a mistake or need to update your information, simply resubmit the form.

## 2. Request a `<course>` repo
Pick the assignment from the **Drop-down Menu** and GitHub will create a private repository for you and invite you to collaborate via this repository. Accept the invite (link is in the confirmation comment), then clone the repository. Re-requesting the same assignment is safe—it returns your existing repo.

## 3. My repos
Just **Submit** (nothing to fill in) → you get a comment listing **all** your repos, with links.

The bot needs **~30 sec to a minute** to process your request.
